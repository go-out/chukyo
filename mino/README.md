現在の岐阜県南部にあたる、木曽三川（木曽川・長良川・揖斐川）の下流に位置する地域

青野原（現在の岐阜県大垣市・不破郡垂井町）は、大和政権の支配下だった畿内と、それより東の「東国（現在の関東地方や東海地方）」との境界線・関所にあたる地域

大野原（現在の揖斐郡大野町・瑞穂市周辺）は、天照大神を祀る最良の地を求めて各地を巡幸した倭姫命が一時的に築いた宮「元伊勢」の一つである「伊久良河宮（いくらがわのみや）」があったとされる地域

各務野（現在の各務原市）は、古代に鏡作部（かがみつくりべ、（銅鏡などの鏡を作る特殊技能集団）がいたと言い伝えられる地域で、近現代には自衛隊岐阜基地などに関連する工業都市として発展した地域
