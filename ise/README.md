全ての神社の上に立つ神社・神社本庁の本宗（ほんそう）である「神宮（じんぐう）」の2つの正宮「二所大神宮（皇大神宮・豊受大神宮）」（一般には「内宮（ないくう）・外宮（げくう）」と呼ばれる）の宮域がある日本国民の総氏神を祀る神聖な場所

* 正式名称は「神宮（じんぐう）」だが、他の神宮と区別するため、一般には「伊勢」の地名を冠する
* 公式には、2の正宮と14の別宮、109の摂社・末社・所管社の合計125社から成り立つ集合体を「神宮」と総称する

古来より「外宮先祭（げくうせんさい）の礼」といい、両宮を参拝する際は外宮〜内宮の順に参るのがしきたりとされる

* 参拝は朝五時から夕方まで（閉門時間は季節により異なる）
* 神前では「二拝（腰を90度に折り深いお辞儀）二拍手（胸の高さで両手を合わせ、右手先を少し下にずらす）一拝（ずらした指を元に戻し、もう一度深いお辞儀）」で感謝の心をささげる
