名古屋市を中心とした県西部の尾張地方

尾張国（おわりのくに、をはりのくに）は、天火明命を祖神とする尾張氏の本拠地（ヤマト王権の天皇家と婚姻関係で結びつき支配を確立）
日本武尊の東征の際に通ったとされ、内々神社や萱津神社など、日本武尊に纏わる神社や地名が多く残る
