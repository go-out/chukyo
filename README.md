東海地方の中で静岡県を除いた愛知県・岐阜県・三重県の3県に跨る日本三大都市圏の一つ

愛知県西部（尾張・東三河）・岐阜県南部（美濃）・三重県北部に広がる「濃尾平野（のうび）」は、名古屋市を中心とする東京都市圏・大阪都市圏に次ぐ経済圏の範囲に相当する
四日市コンビナートなどを中心とする四日市・津などの湾岸都市が連なる「伊勢平野」と、トヨタ自動車（トヨタグループ）の本拠地である豊田市や刈谷市が位置する「岡崎平野」には、日本最大の工業エリア「中京工業地帯」を構成する工場が点在する

（縄文時代以前は、「濃尾平野」「伊勢平野」「岡崎平野」などの大半が海だったと考えられる）

* 岐阜県北部の旧飛騨国（現在の高山市・飛騨市・下呂市など）は、日本アルプスを形成する富山県・長野県などと関係するため、この地図の対象地域から除外
* 三重県の伊賀地域（名張市周辺）は関西（特に大阪・奈良）との繋がりが強く「名古屋圏」から外されるため、この地図の対象地域から除外（また、三重南部も紀伊山地にあたるため対象地域から除外）
